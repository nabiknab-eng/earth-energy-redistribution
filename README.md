# Energy redistribution atlas

Open `index.html` directly in a modern browser. No local server, internet
connection, JavaScript framework, or remote font is required.

`figures/` contains an SVG and PNG fallback for each of ten main figures.
`data/` contains the complete plotted CSV for each figure. `references/` and
`methods/` contain the audit and method documents used to constrain the atlas
text. `audit/external_audit_bundle_v4.zip` contains the source code, reduced
reference results, tests, download specifications, audit documentation, and
checksums needed for independent reproduction from the official raw sources.

The duplicate `energy_redistribution_atlas.html` is byte-identical to
`index.html` and is provided to match the requested descriptive filename.
PDF was intentionally not generated.
